# Bible Plus（Bible+）

一個靜態閱讀應用程式，整合 66 卷聖經（和合本、和修本、新譯本）及 49 部可閱讀的擴充書卷（45 部有中文：6 部採 1933 年舊譯，39 部為中文初稿）。

## 開啟

在此目錄執行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8765/>。請使用 HTTP 伺服器，而非直接開啟 HTML 檔案。無需建置、外部套件或 API 金鑰。部署時只需要根目錄的 `index.html`、`site.webmanifest`、`static/`、`README.md`、`SOURCES.md`、`LICENSE` 及 `NOTICE.md`。

## 閱讀

- 底部選擇書卷、版本、語言與顯示模式；輸入章與節後按「去」。
- 章輸入欄使用數字；遇到重複章號、字母章號或標題篇時，以閱讀順序編號（例如十二族長遺訓為 1–142）。原篇名與章號保留於閱讀標題及按兩下開啟的選單。序言保留於閱讀內容，不列入節的選項，節輸入預設為 1；未分節正文在節輸入欄顯示為 1（僅作導覽用途，並非來源節號）。
- ← → 切換章；↑ ↓ 選取經文。投影模式採大字、全寬顯示，選取經文對齊畫面頂部；Esc 返回標準模式。
- ⓘ 開啟應用版本、閱讀說明、警告及目前書卷來源。日常閱讀不顯示這些說明。
- 網址保留書卷、章、節、版本、語言與顯示模式，可複製作為書籤。

書卷選單依序列出「天主教及東正教增收書卷」「東正教增收書卷」「舊約次經」「新約次經」「典外書卷 / 偽經」，並保留英文名稱。增收以原有66卷為基準，共通書卷不重複列出；各教會完整正典及譯本並未另行下載。未備妥的書卷可選取，頁面顯示「內容尚未備妥」，章節及跳轉控制停用，不會請求或下載經文。

## 內容與來源

聖經提供和合本、和修本、新譯本。`static/data/cuv.json`、`rcuv.json`、`cnv.json` 原樣複製，保留原有 JavaScript 資料封裝，並非一般 JSON。中文經文未修改。英文對照採用 WEB 英式英文版（WEBPB），可選英文或中英對照。

三十九部擴充書卷的英文來源保留原文，對應的正體中文 AI／機器翻譯初稿已補齊至英文底本所提供的內容，尚未經獨立學術審校。若個別資料無法載入，閱讀器仍會顯示缺少內容的提示及可用文本。典外的以斯拉續篇上卷（1 Esdras，9章）與以斯拉續篇下卷（2 Esdras，16章），並非原有聖經的以斯拉記和尼希米記。以斯拉續篇下卷已按原章號合併原先的5 Ezra（1–2章）、4 Ezra（3–14章）及6 Ezra（15–16章）；舊書籤會自動轉到對應章節。來源網址、譯者、版本說明及 AI 翻譯警告均保留於資料及資訊視窗。詳見 [SOURCES.md](SOURCES.md)。

《多比傳》（Tobit）已收錄 WEB Classic 英文全文及正體中文 AI 翻譯初稿，共 14 章、244 節，附中文章節簡題。中文依此英文底本翻譯，並非思高或其他出版中文譯本；不同版本的分節可能不同。

《猶滴傳》（Judith）已收錄 WEB Classic 英文全文及正體中文 AI 翻譯初稿，共 16 章、339 節，附中文章節簡題。已找到思高本《友弟德傳》的線上來源，但未確認可供本專案全文再散布的授權，因此中文另依 WEB Classic 翻譯。

《以斯帖記補編》（Additions to Esther）收錄六段補錄甲至己，英文摘自 WEB Classic 希臘文以斯帖記，中文為另行翻譯的 AI 初稿。章欄 1–6 及節欄共 101 個段落均為閱讀編號，不是原譯本章節號；原文位置記於資料和資訊視窗，英文文字不改寫。

應用程式由根目錄啟動，所有閱讀資料均存放於 `static/data/`。合併前的兩個應用程式目錄已於完成資料一致性及閱讀器檢查後移除。

## 驗證

```sh
node --check static/js/main.js
node --check static/js/books.js
python3 scripts/validate_data.py
```

清理前已通過輕量 DOM 模擬檢查：版本、章節跳轉、特殊編號、缺少語言、雙語呈現、投影定位、對話框、網址還原及原始檔案逐位元組一致性。合併用的閱讀器測試腳本已移除。資料驗證檢查典外書卷章節及中英對齊，不代表學術審校。完整中文覆蓋檢查 `python3 scripts/validate_data.py --require-complete` 目前通過。

本次環境沒有可連線的瀏覽器；尚未完成實際瀏覽器的視覺與行動裝置驗證。

## WEB 英文版本

已收錄 World English Bible British Edition（WEBPB），共 66 卷、1,189 章、31,103 個原來源節條目。來源為 eBible.org 的公版逐節純文字資料，英式拼字並使用 LORD／GOD。與三種中文版本按章節編號對照；WEB 是獨立英譯本，不是中文版本的英譯。

閱讀檔及來源網址、SHA-256、權利說明等資料保存在 `static/data/web/`。原始下載檔已移除，應用程式不依賴這些檔案。原來源含五個空白節，顯示時會提示缺文，不會補譯或移動編號。版次之間的分節差異可能造成同一節內容不完全對應。詳細來源見 [SOURCES.md](SOURCES.md)。

```sh
# 如需核對或重建，先另行下載官方 engwebpb_vpl.zip：
python3 scripts/import_web.py --archive /path/to/engwebpb_vpl.zip --check
python3 scripts/import_web.py --archive /path/to/engwebpb_vpl.zip
```

WEB 經文的公版狀態不受應用程式的 AGPL 授權限制。

馬加比一書（16 章）、馬加比二書（15 章）、所羅門智訓（19 章）及便西拉智訓（51 章）已加入 WEB Classic 公版英文及正體中文翻譯初稿。這四卷的中文以 Google Translate 建立初稿，再作 AI 修訂（部分段落由 AI 直接翻譯），尚未經獨立學術審校，並非思高譯本。《便西拉智訓》包括古代譯者序言；底本原有的 24 個空白條目在兩種語言均保留缺文提示，另保留底本直接略去的 12 個節號，詳見資訊中的版本說明。

《耶利米書信》已加入 WEB Classic 英文（巴錄書第 6 章，73 節），於 App 獨立列作第 1 章。中文已直接收錄信望愛的 1933 年聖公會舊譯，共 73 節；原文及來源記錄保留，本次未另作翻譯。
