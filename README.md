# Bible Plus（Bible+）

一個靜態閱讀應用程式，整合 66 卷聖經（和合本、和修本、新譯本）及 9 部典外書卷。

## 開啟

在此目錄執行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8765/>。請使用 HTTP 伺服器，而非直接開啟 HTML 檔案。無需建置、外部套件或 API 金鑰。部署時只需要根目錄的 `index.html`、`site.webmanifest`、`static/`、`README.md`、`SOURCES.md`、`LICENSE` 及 `NOTICE.md`。

## 閱讀

- 底部選擇書卷、版本、語言與顯示模式；輸入章與節後按「去」。
- 章輸入欄使用數字；遇到重複章號、字母章號或標題篇時，以閱讀順序編號（例如十二族長遺訓為 1–142）。原篇名與章號保留於閱讀標題及按兩下開啟的選單。序言保留於閱讀內容，不列入節的選項，節輸入預設為 1；未分節正文在節輸入欄顯示為 1（僅作導覽用途，並非來源節號）。
- ← → 切換章；↑ ↓ 選取經文。投影模式採大字、全寬顯示，選取經文對齊畫面頂部；Esc 返回標準模式。
- ⓘ 開啟應用版本、閱讀說明、警告及目前書卷來源。日常閱讀不顯示這些說明。
- 網址保留書卷、章、節、版本、語言與顯示模式，可複製作為書籤。

## 內容與來源

聖經三版本均來源於原應用程式的 **MGBC** 資料。`static/data/cuv.json`、`rcuv.json`、`cnv.json` 原樣複製，保留原有 JavaScript 資料封裝，並非一般 JSON。未修改經文，也未新增英文翻譯。未提供英文時顯示提示及現有中文。

典外書卷資料亦原樣複製。中文部分仍未完成，缺少中文時顯示提示及現有英文。來源網址、譯者、版本說明及 AI 翻譯警告均保留於資料及資訊視窗。詳見 [SOURCES.md](SOURCES.md)。

應用程式由根目錄啟動，所有閱讀資料均存放於 `static/data/`。合併前的兩個應用程式目錄已於完成資料一致性及閱讀器檢查後移除。

## 驗證

```sh
node --check static/js/main.js
node --check static/js/books.js
python3 scripts/validate_data.py
```

清理前已通過輕量 DOM 模擬檢查：版本、章節跳轉、特殊編號、缺少語言、雙語呈現、投影定位、對話框、網址還原及原始檔案逐位元組一致性。合併用的閱讀器測試腳本已移除。資料驗證檢查典外書卷章節及中英對齊，不代表學術審校。完整中文覆蓋檢查 `python3 scripts/validate_data.py --require-complete` 目前預期不通過。

本次環境沒有可連線的瀏覽器；尚未完成實際瀏覽器的視覺與行動裝置驗證。
